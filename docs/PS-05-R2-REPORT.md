## Что было видно до исправления

Исходная R1-сборка `W191Kvrm0Ls3y10cyjb_B`, normal motion, light, 1840×944. На настоящем wheel 04 → 05.1 старый блок достиг opacity 0 лишь при `copy.bottom = −12 px`, уже за верхним краем. Новый начинал проявляться (opacity 0,026) при заголовке на `y = 824 px`, возле нижнего края. [Видео R1](../design/photonic-skin/ps-05-r2/2026-09-25/baseline/04-to-05.1/transition.webm), [кадры R1](../design/photonic-skin/ps-05-r2/2026-09-25/baseline/04-to-05.1/timeline.png), [покадровая геометрия R1](../design/photonic-skin/ps-05-r2/2026-09-25/baseline-trace/04-to-05.1/trace.json).

Причина подтверждена кодом и кадрами: R1 вычислял opacity по смещению секции и, в reading layout, по пересечению copy с границей viewport. Native scroll перемещал родителя почти на экран до завершения fade. Численные промежуточные alpha существовали, но визуальный уход происходил у края.

## Что изменено

- В `app/_ps05/motion.ts` единая кривая обмена задаёт исходящему блоку opacity 0 при смещении секции примерно на 0,34 viewport, а входящему — 0 уже в области чтения. Компенсация перемещения родителя оставляет видимое локальное движение около 28 px; длинный reading-раздел сохраняет читаемое плато до границы главы.
- Сильный wheel и программный скачок используют тот же runtime-clock. Последний видимый прямоугольник исходящего текста запоминается до скачка. Краткоживущий декоративный `inert`-слой вынесен из обновляемого React-дерева, чтобы быстрый wheel не удалял его до fade. У слоя нет pointer events, ID, имён полей, tab stops или повторного чтения screen reader; после обмена он удаляется.
- Скрытые оригинальные copy-блоки не принимают указатель и становятся `inert` при нулевой alpha; после полного проявления действия снова доступны. Header, граф, Canvas и сам Мимик в обмен не включены.
- В `app/_ps05/layout.ts` измеренные начала секций округлены к CSS-пикселю: при reading layout 1440×900 это убрало случай, когда видимая секция начиналась на 0,14 px раньше целочисленного scrollY, а активным оставался предыдущий экран.
