# Mimicry group — Photonic Skin

## Контекстный checkpoint и предметная карта экранов

Дата: 4 августа 2026  
Статус: рабочая фиксация перед D‑R4; формы показаны как предметные концепты, но ещё не утверждены для production.

## 1. Что уже зафиксировано

- Позиционирование: Mimicry group — агентство корпоративных коммуникаций, создающее спецпроекты для сотрудников.
- Brand essence: «От важной темы — к общему действию».
- Смысловая система: `смысл → участие → запуск`.
- Двойной вход:
  1. `Собрать проект целиком`.
  2. `Подключить отдельную компетенцию`.
- Семь производственных компетенций: контент, дизайн, event, игры, видео, digital, мерч.
- Контексты (не компетенции): изменения, событие, обучение, HR‑brand‑активация.
- Цвет закреплён только за семью компетенциями; комплексный проект не получает восьмой цвет.
- Два равноправных визуальных направления для дальнейшего сравнения: Photonic Skin и Living Mimic. Сейчас разрабатывается Photonic Skin.
- Основная страница — одностраничная; отдельные страницы требуются только для подробных кейсов.
- PS‑03.4R / D‑R3 технически прошёл, но предметная узнаваемость не была достигнута. PS‑03 не закрыт. Следующий визуальный проход — D‑R4 с явно предметными формами.

## 2. Что нельзя считать утверждённым

- Конкретные предметы D‑R4 пока являются кандидатами.
- «Креатив» и «обучение» не добавляются как восьмая и девятая компетенции.
- Лампочка может быть мотивом задачи/идеи, но не получает отдельный competence color.
- Выпускная шапочка и книга — состояние комплексного решения «Обучение», окрашенное цветами реально задействованных компетенций.
- Точная motion‑пластика трансформации не зафиксирована без повторного просмотра исходного видео‑референса.
- Production‑архитектура мимика должна быть пересмотрена, если истинное расщепление на отдельные предметы остаётся обязательным.

## 3. Рекомендуемый маршрут одностраничного сайта

1. Sticky navigation.
2. Hero с двойным входом.
3. Условно раскрываемая горизонтальная ветка «Собрать проект»:
   - шаг 1 — задача сотрудника + лёгкие context chips;
   - шаг 2 — рекомендованные форматы + сборка компетенций;
   - шаг 3 — резюме проекта + CTA «Запросить предложение»;
   - `+1` — модальная форма.
4. Доказательства: клиенты, цифры, короткие подтверждения.
5. Кейсы комплексных проектов.
6. Горизонтальная витрина семи компетенций.
7. «Как мы работаем»: смысл → участие → запуск.
8. Короткий блок «О нас / команда».
9. Компактный блок «Закупкам».
10. «Связаться с нами».
11. Юридический footer.

На mobile горизонтальные сцены превращаются в вертикальный scroll‑snap или обычный последовательный поток. На desktop колесо/трекпад могут управлять pinned‑сценой, но не создают вложенный нативный горизонтальный скролл внутри вертикального.

## 5. Правила масштаба Photonic Skin

- Все предметы используют один и тот же базовый модуль фасета; мелкие детали упрощаются, а фасеты не уменьшаются бесконечно.
- Стартовая гипотеза: длинная ось фасета ≈ `D/42…D/48` от диаметра hero‑сферы.
- Минимальная конструктивная толщина предметной детали: 4 модуля; комфортная — 7 модулей.
- Через‑отверстия (палитра, ручки, горловины) при общей сферической топологии должны быть ложными тёмными углублениями либо требуют другой топологии.
- Single‑экран может показывать основной предмет и 1–2 аксессуара. Complex‑экран использует только один primary object на компетенцию.
- Суммарная визуальная масса композиции остаётся близкой к массе hero‑сферы; при добавлении предмета масса перераспределяется, а не клонируется.
- В single‑состоянии присутствует только один хроматический hue, но перламутровый нейтрал остаётся материалом и бликом. Сплошная насыщенная заливка запрещена как production‑норма.

## 6. Motion‑грамматика

### Idle

- доминирующая ось поворота + слабая вторая ось;
- амплитуда 2–4°, без полного постоянного вращения;
- один цикл микродыхания 8–12 секунд;
- цветовая волна — редкое событие, а не непрерывная «бегущая строка»;
- после взаимодействия объект фиксируется на 3–5 секунд;
- reduced motion получает статическое финальное состояние.

### Transform

`сжатие массы → вытягивание тёмного ядра → направленное перераспределение фасетов → надувание предметных силуэтов → фиксация кожи → единая световая волна`.

Запрещены исчезновение/появление массы, обычный crossfade, хаотичные частицы, взрыв, slime‑капли ради эффекта и постоянная пульсация.

## 7. Техническая развилка

Обычные morph targets с фиксированной связной топологией не могут честно создать несколько полностью разъединённых объектов или изменить род поверхности. Сфера не превращается в настоящий объект со сквозными отверстиями без мембран, а расщепление требует тонких связующих мостов.

Если истинное расщепление обязательно, рекомендуемая архитектура:

1. Тёмное ядро — изменяемый SDF/metaball‑объём, допускающий смену топологии.
2. Кожа — фиксированное число GPU‑instanced фасетов одного размера.
3. Для каждого target object хранится SDF и целевой набор surface points.
4. При выборе компетенций фасеты перераспределяются между target surfaces; новые фасеты не создаются.
5. Desktop получает precomputed position textures / baked transitions; mobile и reduced motion — статические постеры или короткие prerendered loops.

Если сохраняется D‑R3 fixed‑topology master mesh, визуально допустимы только предметы, соединённые тонкими перемычками, и ложные отверстия. Это принципиальный выбор до разработки сайта.

## 8. Логические риски и принятые коррекции

1. **Taxonomy drift.** «Креатив» и «обучение» ошибочно начали вести себя как компетенции. Коррекция: остаются семь компетенций; обучение — решение/контекст.
2. **Дублирование книги.** Книга одновременно предлагалась для контента, обучения и контактов. Коррекция: книга остаётся у контента и составного решения обучения; контакты получают конверт + карточку.
3. **Взрыв количества объектов.** Полный набор каждой компетенции даёт до 17–20 предметов в complex‑state. Коррекция: в сборке используется один primary object на компетенцию.
4. **Противоречие fixed topology и расщепления.** Решается технической развилкой из раздела 7.
5. **Декоративная «обивка».** Равномерно насыщенные фасеты делают предметы похожими на брендированные сувениры. Коррекция: 35–65% нейтрального перламутра и управляемые цветовые зоны.
6. **Scroll‑ловушка.** Несколько вложенных горизонтальных каруселей конфликтуют с трекпадом и mobile. Коррекция: pinned narrative + snap на desktop, вертикальный fallback на mobile.
7. **Motion overload.** Одновременные вращение, дыхание, геометрическая пульсация и постоянный цветовой бег мешают чтению. Коррекция: одно доминирующее idle‑движение и редкие события.

## 9. Что требуется согласовать следующим

1. Состав предметов каждой из семи SINGLE‑форм.
2. Используем ли аксессуарные группы только на SINGLE, а primary objects — в complex‑сборке.
3. Контактный объект: конверт + карточка вместо третьей открытой книги.
4. Допустимы ли тонкие соединительные мосты, или требуется истинное расщепление через SDF/instanced‑skin.
5. Повторно приложить видео‑референс трансформации для точной пластики времени, траекторий и вязкости.
