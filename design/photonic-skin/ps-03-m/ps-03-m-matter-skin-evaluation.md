# PS-03.M — Matter & Skin Architecture: evaluation

Дата: 2026-08-05. Статус: технический spike завершён, все машинные QA-проверки пройдены.

## Что доказано

Полный цикл `sphere → open book → gamepad + queen → sphere` воспроизводимо работает
в изолированном Browser Lab (`/visual-lab/matter-skin`) при строго постоянных
8192 ID чешуек, сохранении объёма с ошибкой ~1e-16 (норматив ±1%) и настоящем
разделении вещества на два компонента (без crossfade и скрытой мембраны).

## Архитектура

- **Вещество** — аналитические SDF-поля (`scripts/sdf_targets.py`) на общей сетке.
  Переходы вещества — интерполяция SDF с управляемой шейкой (bridge-капсулы,
  которые растут и распадаются по smoothstep), что даёт честное изменение числа
  связных компонентов: 1 (sphere) → 1 (book) → 2 (gamepad+queen) → 1 (sphere).
- **Кожа** — 8192 GPU-instance плоских чешуек (один `InstancedMesh`, 2 draw calls
  вместе с matter-подложкой). Атрибуты на инстанс: id, позиция (uint16-квант),
  октаэдрическая нормаль, scale, state (surface/transition/reserve), цвет+chroma,
  компонент, вращение.
- **Таргеты** — процедурные watertight-меши из SDF через marching cubes
  (`exports/meshes/*.obj`), валидация: manifold, 0 loose vertices, 0 degenerate
  faces, положительные объёмы.
- **Offline** — весь solve в Python (numpy/scipy/scikit-image), seed 20260805,
  детерминизм подтверждён совпадением SHA256 двух последовательных сборок
  (`2232fe39…`). Solve: 142.6 s.
- **Браузер** — только playback запечённых key states (36 строк × 81 920 байт),
  WebGL 2, без WebGPU-зависимости.

## Соответствие ID

Иерархическое, без плотной матрицы 8192×8192: предгруппировка по компонентам →
k-means 48 регионов → Sinkhorn (eps=0.05) c целочисленными потоками → блочный
Hungarian → swap-релаксация. Стоимость: `wd*|Δp|² + 0.35*(1−n·n′)`.

## Транзиции

5 фаз на сегмент (tension → submerge → transport → emerge → stabilize), 13 key
states на сегмент, flow-field перенос со стратификацией по глубине, тангенциальная
репульсия и жёсткий 3D-floor (мин. дистанция ≥ 0.28ℓ по всем ключам), темпоральное
сглаживание нормалей (flips ≤ 26 из 8192 на худшем сегменте). Neighbor graph
запечён по key states; после split нет ни одной связи между компонентами.

## Известные ограничения

1. **Дефицит кожи на book/game**: при площади ~24 (вдвое больше сферы) видимые
   чешуйки работают на потолке scale 1.15 — покрытие разреженнее, чем на сфере.
   Диапазон не расширялся; зафиксировано как дефицит (см. `surface_scale: 1.15`
   в манифесте). Для production потребуется либо больший бюджет, либо
   переменная плотность по зонам.
2. Середина transport-фазы читается «роем»: matter-подложка рендерится плитами,
   непрерывная поверхность вещества в браузере не визуализируется.
3. Neutral share game-состояния 54.3% — чуть ниже нормы сферы (55–65%),
   норматив формально задан только для sphere.
4. Idle-motion — минимальный (дыхание/микроповорот), финальный production shader
   не разрабатывался (вне рамок этапа).
5. GPU-память и низкоуровневые лимиты не замерялись (нет инструментов в среде).

## Вердикт

Hybrid «SDF-вещество + instanced skin» подтверждён как кандидат production-
архитектуры: сохранение массы, стабильные ID, настоящий split/merge и
производительность запаса (6 ms/frame при 2 draw calls) доказаны. Рекомендуемый
следующий минимальный этап — PS-03.M2: перенос C-R1 SINGLE-форм D-R3 в новый
пайплайн как SDF/mesh-таргеты + бюджет кожи с зонной плотностью.
