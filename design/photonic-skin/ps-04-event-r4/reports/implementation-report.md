# Event R4 — единая форма трёх фигур

**Визуальная приёмка:** владелец принял переделку Event в следующем сообщении.

## Исправлено

Правая для наблюдателя фигура — компонент `figure-left` после поворота Event.
Предыдущая правка заменила её исходную геометрию на отдельный силуэт, а R1
дополнительно сдвинул одиночную фигуру по X на 0.251 единицы. Место её
первоначального соединения с настилом осталось видимым рядом с новой фигурой.

R4 заново семплирует исходный компонент `figure-left` из авторской геометрии
`event-stage-figures`: он использует тот же tapered_capsule + sphere, что и
две другие фигуры. Его положение восстанавливается по неизменённым точкам
настила каждого состояния. Таким образом восстановлено и соединение с
настилом; отдельного выступа у основания на проверенных кадрах больше нет.

Обновлены все 203 состояния с Event, включая SINGLE, GATHER, DRIVE и прочие
производные. Для каждого состояния заменены все позиции, нормали и ориентации
правой фигуры. ID, активность, scale, palette ownership, LOD и остальные
компоненты побайтно сохранены. Архивные M5.5, M6.1, R1 и Video R2 не изменены.
Новая заплатка применяется после R1 и Video R2, проверяются SHA-256 источника,
заплатки и результата. Текущая главная `/` получает Event R4 автоматически.
