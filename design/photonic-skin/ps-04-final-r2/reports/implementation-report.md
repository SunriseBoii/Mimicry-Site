## Что исправлено

### Резервные частицы и Event

В R2 право частицы отображаться отделено от численного минимального масштаба. Неактивная в обоих endpoint частица имеет нулевую площадь треугольников; появление и исчезновение плавные. У Games скрываются 4 779 резервных частиц, у Video — 3 378. Диагностический режим reserve по-прежнему может показывать их явно.

На финальных кадрах облака точек отсутствуют. Под правой фигурой Event после исправления видимости отдельный артефакт не наблюдается. Поэтому дополнительная деформация Event не выпускалась: утверждённая R1-геометрия Event и все её производные сохранены.

### Video в составных формах

Выпущены 190 заплаток: все 126 GATHER/DRIVE наборов builder с Video, а также 64 другие производные композиции. Камера и хлопушка масштабируются и перемещаются одной группой. Исходный участок восстанавливается из авторского определения **по активным частицам**, резервная сфера в расчёт размера не входит. Масштаб позиций применяется и к размеру чешуек.

После подгонки проверяется расстояние от активных частиц других предметов в проекции штатной камеры с запасом на размер чешуек. Минимальный расчётный зазор — 0.12004 NDC; при мобильной области актёра 202.8 px это примерно 12.2 px до дополнительных множителей композиции, выше требования 6 px. Desktop также имеет запас относительно 12 px. Все остальные компоненты остаются побайтно прежними. Одиночный Video не изменён.

Manifest в `public/photonic-skin/ps-04-final-r2/manifest.json` проверяет хэш исходного R1/frozen состояния, каждой заплатки и конечного буфера. Формат заплатки: ID, позиция, масштаб; normals, orientation, palette ownership, status, flags, LOD и остальные поля не меняются. [Полная геометрическая проверка](geometry-proof.json).

### Чешуйки и фон

R2 использует отдельную геометрию тонкой выпуклой ромбовидной чешуйки с узкой кромкой, 16 треугольников на экземпляр. Число экземпляров и их ID прежние. Светлая основа `#FCFCFA`, roughness 0.32; направленный студийный свет, слабый угловой перламутровый оттенок отражения. Тёмный материал имеет отдельные настройки roughness/specular/metalness. Смысловые цвета компетенций сохранены.

Фон светлой страницы и загрузочного состояния: `#F2F2F0` с радиальным высветлением до `#F6F6F4`. Canvas прозрачен. Оценка сходства материала с художественным референсом остаётся визуальной, её нельзя заменить тестом.

### Быстрые переходы

Исправлены подтверждённые пути рассинхронизации:

1. Стрелки выбирают следующий узел от принятого destination контроллера, а не от запаздывающего React `activeNode`.
2. Пока готовится программа новой ревизии, старая программа удерживает последний progress; прежнее принудительное значение `1` вызывало скачок к старому предмету.
3. Geometry ack и пара endpoint сохраняются после фактического draw, а не перед ним. Пробы mask/framebuffer не считаются экранным draw.
4. Новый source строится из последней нарисованной пары, её progress и палитры. Presentation frame вычисляется по **старой** паре, а не по новому destination.
5. Дробная видимость чешуек запекается в масштаб снимка: округление activation к status больше не вызывает вспышку частиц при retarget.
6. Поздние результаты не проходят проверку текущей ревизии. Замена GPU-сэмплеров и программы атомарная. Цвет старой формы удерживается во время подготовки.
7. Быстрые действия на 03.2 больше не публикуют старый cancel, который мог отменить уже заменивший его запрос и ложно объявить новую форму settled.
8. Возврат wheel-жеста к прежнему закреплённому экрану повторно сверяет semantic endpoint: ранее ранний морф к соседу мог остаться после возврата к исходному экрану.

Маршрутная длительность сохранена: 650 ms desktop / 550 ms mobile. CPU и GPU используют согласованную длительность, включая снимки с начальной скоростью.

Тяжёлое вычисление snapshot/compile вынесено в Web Worker. Неактуальный live-retarget отменяется; до двух свободных воркеров переиспользуются. Старые GPU-текстуры освобождаются после полной отрисовки замены: в циклическом прогоне рост с 16 до 160 устранён, наблюдается ограниченное число 32. Расчёт textureMiB для R2 теперь учитывает реально удерживаемые текстуры.

## Метрики и ограничения приёмки

Проверенный desktop GPU: Intel Iris Xe, ANGLE D3D11, Edge. Это аппаратный рендер на данном ноутбуке. Мобильные размеры эмулированы на нём же; **реальный телефон не проверен**.

До Worker встречались интервалы кадров до 577 ms; после переноса вычисления в первом повторном desktop-прогоне p95 составил 13.7 ms, максимум 71.3 ms. Итоговые трассы находятся в папках кадров. Эти показатели относятся к конкретным прогонам, а не гарантируют производительность всех устройств.

[Итоговая сводка кадров](frame-summary.json): R2 desktop p95 13.1 ms / max 34.5 ms; мобильный размер на том же ноутбуке p95 11.8 ms / max 37 ms. В обеих сериях все девять замен программы начинались с progress 0. R1/R2 кадры совпадают по заданной сцене и фазе цвета; служебный значок Next.js на части R2 кадров относится к dev-записи, на production-странице его нет.

[Первое заметное изменение пикселей](pixel-latency.json) измерялось отдельно в неподвижной области builder через CDP screencast, JPEG90, с зафиксированной фазой палитры. На production-сборке шесть действий дали **61.9–312.9 ms**. Это небольшая диагностическая выборка, включает dispatch ввода и подготовку, не является аппаратным presentation timestamp. Ранее предложенный предел 150 ms **не достигнут на каждом действии**; его нельзя отмечать PASS. Основной поток при подготовке продолжает отрисовку; текущая форма сохраняется.

До закрытия PS‑04 остаются визуальная приёмка материала/движения владельцем, аппаратный мобильный прогон и, если предел 150 ms остаётся обязательным, дополнительная оптимизация холодной подготовки builder. UX/UI и наполнение PS‑05 в этой работе не перерабатывались.

1. `npm run dev -- --port 3001` либо `npm run build` и `npm run start -- --port 3002`.
2. `node design/photonic-skin/ps-04-final-r2/scripts/browser-qa.mjs`; параметры окружения: `PS04_QA_URL`, `PS04_MOBILE=1`, `PS04_REVISION=r1`.

4. Генератор: Python + NumPy/SciPy/Pillow, `design/photonic-skin/ps-04-final-r2/scripts/build_release_geometry.py`. В текущем workspace SciPy установлен в исключённую из Git папку `artifacts/ps04-r2-python`; для него требуется соответствующий `PYTHONPATH`.

Замороженные M5.5/M6.1 payload и R1 release-патчи не переписывались. Граница новой визуальной версии задаётся `stage="final-r2"`.
